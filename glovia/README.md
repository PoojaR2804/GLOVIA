
# GLOVIA – Skincare & Personal Care E-Commerce Website

## About the Project
GLOVIA is a skincare and personal care e-commerce website developed using React.js. It allows users to explore skincare products, view product details, add products to their cart and wishlist, and place orders through a simple checkout process.

The main aim of this project is to provide users with a simple and user-friendly online shopping experience for skincare and personal care products.

## Features
- 🏠 Home page with featured products
- 🛍️ Browse and view skincare products
- 🔍 View detailed product information
- ❤️ Add and remove products from the wishlist
- 🛒 Add products to the cart and manage quantities
- 👤 User registration and login pages
- 🔑 Forgot password page
- 💳 Checkout and simulated payment process
- 📦 Order success and order tracking pages
- 📋 View previous orders
- 💾 Local storage to save cart, wishlist, and order details

## Technologies Used
- React.js
- JavaScript
- HTML5
- CSS3
- React Router
- Browser Local Storage
- Vite

## Installation and Setup

### 1. Clone the Repository
```bash
git clone https://github.com/PoojaR2804/Glovia.git
```

### 2. Navigate to the Project Folder
```bash
cd Glovia/glovia
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start the Development Server
```bash
npm run dev
```

Open the local URL shown in the terminal to view the website in your browser.

## Note
This is a frontend project. The login, cart, wishlist, order management, and payment features are implemented using browser local storage and simulated functionality. It does not use a real backend or process real payments.
